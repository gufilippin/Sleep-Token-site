# Gustavo-Filippin-trabalho-final-git

## Sobre o projeto

Este projeto consiste em uma Landing Page desenvolvida como atividade prática da Unidade Curricular de Versionamento e Colaboração.

A página apresenta informações e elementos visuais relacionados à banda Sleep Token, com destaque para o álbum "Even in Arcadia". O site também disponibiliza links para ouvir o álbum em diferentes plataformas, como Spotify, Apple Music, Amazon Music e YouTube.

O projeto foi desenvolvido para aplicar na prática conceitos de desenvolvimento web, versionamento de código e utilização do Git e GitHub.

## Tecnologias utilizadas

- HTML5 — estrutura e organização do conteúdo da página.
- CSS3 — estilização, layout, efeitos visuais e responsividade.

## Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/gufilippin/Gustavo-Filippin-trabalho-final-git.git
```

2. Acesse a pasta do projeto:

```bash
cd Sleep-Token-site
```

3. Abra o arquivo `index.html` em um navegador da sua preferência.

## Estrutura do projeto

- `index.html` — página principal da Landing Page.
- `style.css` — estilos, layout, efeitos visuais e responsividade.
- `img/` — imagens utilizadas na página.
- `.gitignore` — arquivos e padrões que não devem ser versionados.
